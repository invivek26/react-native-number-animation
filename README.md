# react-native-number-animation

High-performance native rolling number animations for React Native

## Installation


```sh
npm install react-native-number-animation
```


## Usage


```js
import { NumberAnimationView } from "react-native-number-animation";

// ...

<NumberAnimationView color="tomato" />
```
